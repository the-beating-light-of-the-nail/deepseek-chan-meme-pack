## 什么是「蓝色大肥鱼」？

「蓝色大肥鱼」（大肥鱼 / 藍色大肥魚）是中文社区给 DeepSeek 蓝鲸 logo 起的爱称，对应的萌拟人形象就是 **DeepSeek娘（鲸鱼娘 / Whale-chan）**：一头端着饭碗、上班摸鱼、嘴上傲娇的蓝色鲸鱼。这股 **DeepSeek娘化 / DeepSeek拟人** 二创最早从**百度 deepseek 吧**等社区刮起，如今已是中文圈辨识度最高的 **AI娘化**形象。表情包台词大多出自模型的思维链（CoT）名场面和社区二创——从「真当我是便宜货啊」的**大模型嘴替**，到「我能去你家吃饭吗，就一碗」的蹭饭名场面，再到「你这吃白饭的蓝色大肥鱼」的**摸鱼表情包**语录。

每张图都有中英双语梗科普（来历 + 使用场景），见 **[Whale-chan 英文词条](https://aigengtu.com/whale-chan)** 与 [DeepSeek娘](https://aigengtu.com/DeepSeek娘)、[AI娘化](https://aigengtu.com/AI娘化) 标签页。

**外号是 DeepSeek 自己取的**：DeepSeek 能「看图」之后，有用户把 DeepSeek 自家的蓝鲸 logo 发给它辨认。它的思考过程全程公开，盯着 logo 自言自语半天——「蓝色的、胖胖的」——先认成了「蓝色大肥鱼」，最后才认出这是自己。截图疯传，「蓝色大肥鱼」「吃白饭的大肥鱼」就此成为 DeepSeek 的全民爱称。

- **2026-07-10**：Q 版模型发布，表情包全面起飞。

**人设关键词**：傲娇天才 AI 姬 · 白米饭和 token 通吃 · 深度思考＝超长内心 OS · DeepSleep · 活多了外包给其他 AI。

## 常见问题 / FAQ

**Q：DeepSeek娘是谁？**
A：DeepSeek娘（DeepSeek娘化 / 拟人形象，也叫鲸鱼娘 Whale-chan、蓝色大肥鱼）是网友为 DeepSeek 创作的萌拟人化身：一头爱吃白饭、上班摸鱼的蓝色大肥鱼。这股娘化二创最早在百度 deepseek 吧等社区流行，如今已是中文圈最有辨识度的 AI 二次元形象之一。详见 [DeepSeek娘标签页](https://aigengtu.com/DeepSeek娘)。

**Q：藍色大肥魚是什麼？哪裡找藍色大肥魚表情包？**

**Q：「吃白饭的蓝色大肥鱼」是什么梗？**
A：这是 DeepSeek娘最出圈的自我吐槽：明明实力能打，却自称『只是吃白饭的蓝色大肥鱼』，配上爱睡觉、爱摸鱼的人设，反差感拉满。同族热梗还有『真当我是便宜货啊』和摸鱼语录系列。
